🚨 The Vulnerability — Reflected XSS

Reflected XSS occurs when user input is embedded directly into the page HTML without sanitisation. The malicious script executes in the victim's browser immediately.

// ❌ VULNERABLE
const q = new URLSearchParams(location.search).get('q');
resultsDiv.innerHTML = `Results for: ${q}`;
// q = <img src=x onerror=alert(1)> → alert fires!

✅ The Fix

Use textContent instead of innerHTML, or use a sanitiser like DOMPurify.

// ✅ SAFE option 1 — textContent
resultsDiv.textContent = `Results for: ${q}`;

// ✅ SAFE option 2 — DOMPurify
import DOMPurify from 'dompurify';
resultsDiv.innerHTML = DOMPurify.sanitize(q);
